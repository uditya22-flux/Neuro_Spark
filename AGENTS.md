## Developer-only architecture analysis

Graphify is used only against allowlisted source trees (`backend/src` and
`flutter_app/lib`). Never pass datasets, intake text, telemetry, uploads,
exports, secrets, generated graphs, `work`, or `outputs` to Graphify. Use its
code-only extraction mode. Treat a direct import or payload path from
`childExperience` to `adultExploratoryNote` as a release blocker.

## Review policy

Ponytail `lite` is the default implementation review. Run `@ponytail-review`
after each milestone. Its minimalism guidance never removes validation,
authorization, privacy/purge, safeguarding, accessibility, or charter tests.

## Data and release policy

Use synthetic data only in CI. Production requires verified guardian consent,
an approved parent-verification adapter, commercial LLM DPA/zero-retention
approval, safeguarding owner/SLA, and legal approval of privacy copy.
