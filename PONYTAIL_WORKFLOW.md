# Ponytail developer workflow

Ponytail is a developer review plugin, never a runtime dependency. Once the
Codex CLI plugin marketplace is available in a normal developer terminal:

```powershell
codex plugin marketplace add DietrichGebert/ponytail
codex plugin add ponytail@ponytail
```

Use `lite` for normal implementation work and `@ponytail-review` after every
milestone. Treat its minimalism rule as subordinate to authorization,
validation, accessibility, safeguarding, retention/purge, and scope tests.
